# إتزان — رفيقك الذكي للمهام والطاقة

تطبيق ويب عربي (RTL) لإدارة المهام اليومية ومتابعة الطاقة والتركيز، مصمّم بواجهة عصرية بخط IBM Plex Sans Arabic، ويعمل بالكامل داخل المتصفح دون أي خادم أو قاعدة بيانات.

## المزايا

- **جدولك الحي**: عرض مهام اليوم في خط زمني مرتّب حسب الوقت.
- **إضافة المهام بسرعة**: تفريغ الأفكار وتحويلها إلى مهام في ثوانٍ.
- **إنجازاتك وملخصك**: إحصاءات المهام المكتملة ومعدل الإنجاز.
- **المتابعة الذكية**: مساعد ذكي مبني على Gemini API (اختياري — يحتاج مفتاح API خاص بك).
- **وضعان للعرض**: نهاري ناصع وكحلي ليلي فخم، مع تبديل فوري.
- **حفظ محلي**: بياناتك تُخزَّن في `localStorage` داخل جهازك فقط.
- **تصميم متجاوب**: يعمل على الجوال والحاسب.

## التشغيل محليًا

افتح ملف `index.html` مباشرةً في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8000
```

ثم افتح: `http://localhost:8000/`

## النشر

يُستضاف التطبيق عبر **GitHub Pages** على رابط مباشر يعمل بـ HTTPS:

> `https://<username>.github.io/etizan-app/`

## ملاحظة أمنية

مفتاح Gemini API غير مضمَّن في الملف (`apiKey = ''`)، ويجب إدخاله في بيئة التشغيل عند استخدام الميزات الذكية. لا ترفع أي مفاتيح حقيقية إلى المستودع.

## التقنيات

- HTML5 + CSS3 (متغيّرات CSS للثيمات)
- Tailwind CSS (CDN)
- JavaScript خالص (بدون أُطر عمل)
- IBM Plex Sans Arabic
- Gemini API (اختياري)
